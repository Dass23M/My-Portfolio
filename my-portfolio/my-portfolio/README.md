# Portfolio Website

A modern, responsive portfolio website built with Next.js, Tailwind CSS, and SendGrid for contact form functionality.

## Features

- ⚡ **Fast Performance** - Built with Next.js for optimal speed
- 🎨 **Modern Design** - Styled with Tailwind CSS
- 📱 **Responsive** - Works perfectly on all devices
- 📧 **Contact Form** - Integrated with SendGrid for reliable email delivery
- 💬 **WhatsApp Integration** - Direct messaging capability
- 📄 **CV Download** - Easy resume access for potential clients

## Tech Stack

- **Framework**: Next.js 14
- **Styling**: Tailwind CSS
- **Icons**: Heroicons
- **Email Service**: SendGrid
- **Deployment**: Vercel
